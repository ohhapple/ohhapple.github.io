### ✨ Key Features

- Modify Carpet rules on the fly (no game restart required)
- Execute custom commands
- Real-time Minecraft console output monitoring

### 📋 Requirements

- Java version: ≥ 11 (JDK 11 or higher)
- OS: Developed on Windows; other systems have not been tested
- Minecraft version: ≥ 26.1 (a compatible Carpet Mod version is required)

### 🚀 Quick Start

- Make sure **Java 11 or later** is installed (run `java -version` in a terminal)
- Download and extract the project archive to any folder
- Double-click `MCModifier**.jar` or run `Run.bat` to launch the program

### ⚠️ Precautions (Must read)

- No response after double-click: 1. Check that Java 11 or newer is installed; 2. If Java is not recognized, configure the environment variables or run it from a terminal; 3. Keep all files in the same directory.
- Injecting from a path containing Chinese characters may fail. Garbled text may appear if the Minecraft process name contains Chinese characters; this is a known limitation.
- If you find a bug or have a suggestion, submit an [issue](https://github.com/ohhapple/MCModifier/issues).
- Do not share log information. With a genuine Minecraft login, the process name may contain the player's UUID and authentication information. Protect your privacy; you are responsible for the consequences.
